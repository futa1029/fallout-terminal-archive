# Charleston Capitol Building（チャールストン議事堂ビル）

アパラチア準州の政治の中枢、チャールストン議事堂ビル。

大戦後、下院議長アビゲイル・プールの下でチャールストン緊急政府が結成され、レスポンダーと同盟を結び、ブラザーフッドやフリーステイツとの和平も模索しました。

そんな政治の舞台で見つかるのが、プール議長とホルブルックの口喧嘩を録音した「Christmas plans」。物資が枯渇する中でクリスマスパーティーを強行するプール議長と、激怒するホルブルック。

「サンタの衣装を着せてあげてもいいわ」
「絶対に!!やら!!ない!!!」

大統領からの手紙には「反対意見の迅速な鎮圧に賞賛」という不穏な一文。ホーンライト家からは露骨な脅迫状。Falloutの政治は終末後もブレません。

🏛️ モデルは実在するWV州議事堂。金箔ドームは合衆国議事堂より高いんです。
