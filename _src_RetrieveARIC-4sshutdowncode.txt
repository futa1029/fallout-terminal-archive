'''Retrieve ARIC-4's shutdown code''' is a [[Wild Appalachia quests#Miscellaneous quests|miscellaneous quest]] in the ''[[Fallout 76]]'' [[Fallout 76 updates|update]] ''[[Wild Appalachia]]''.

==Walkthrough==
This is a miscellaneous quest while doing [[Project Paradise]] that allows the player character to shutdown ARIC-4. To do this, talk to [[Quercus]] or go to the mainframe terminal. One needs to go through [[Arktos Pharma biome lab|Habitats]] A, B, and C to get the [[Biome lab: Code fragments]] which are notes that reveal the code.

After acquiring the code, go to the security door in a tunnel and then go down the stairs to a big laboratory. Go to the bottom room and there will be a terminal. Once one gets the shutdown code, go to the mainframe terminal upstairs and there will be a terminal option called "Initiate Shutdown."

==Notes==
If this miscellaneous quest is completed while Project Paradise is active, the player will receive the [[Backpack (Fallout 76)#Skins|Arktos Pharma backpack skin]] upon completion of the quest. Retrieving the shutdown code while Project Paradise is not active will not yield any rewards.
