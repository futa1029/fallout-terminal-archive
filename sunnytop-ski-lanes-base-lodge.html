Sunnytop Ski Lanes Base Lodge
サニートップ・ベースロッジ

概要

サニートップ・ベースロッジ（Sunnytop Ski Lanes base lodge）は、アパラチアの荒れた境域にあるロケーションである。

サニートップ・スキー場の一部であるこの建物は、スキー用スロープのベースロッジだった。主なアトラクションは丘の上の大きなサニートップ・コンプレックスにあったため、この建物では最低限のサービスしか提供されていなかったが、夜間のクロッグダンス教室はここで開催されていた。
名物の二人三脚スキーレースで過去に14人の怪我人が出るという事件が起きた後、このロケーションは非難を浴びた。この一件を受け、宣伝は否定的な噂を呼び、マスコミやメディアの注目を集めた。リゾート・ディレクターのテッド・オーギュスティンは、「彼らのほとんどは」また歩けるようになるだろうとリゾートのスタッフに請け合っていたという。数年後、ベースロッジはレイダーであるダイハーズの住処として利用されるようになったが、彼らの大半は丘の上のメインロッジに居住していた。

レイアウト

メインのサニートップ・スキー場コンプレックスの東側に位置するこのロッジは、裏手にスキーリフトがある2階建ての建物である。各階に1つずつ、合計2つの出入口がある。男性用トイレには、個室のドアの1つに張力トリガー式トラップが仕掛けられており、ドアを開けると爆発する。

主なアイテム

  • サニートップ職員のメモ: 1階の入口の右側にあるチェックインエリアのカウンターの上。
  • ボブルヘッド (2か所):
    • 北西の隅、駐車場を見下ろす窓の近くにあるカウンターの上。背景のロッカーのそば、青いレジの横。
    • 2階のターミナルコンソールの上、アマチュア無線機の左側。
  • 雑誌 (2か所):
    • ロッジの外側東側、緑色のトタン屋根のデッキ。小さく積み上げられた木箱、青いタル、パレットの後ろ。
    • 2階バルコニーの中二階の下、ヤオグアイの頭部が剥製として飾られている大きな石造りの暖炉のそばの赤いテーブルの上。
  • アーマーの設計図: 2階にある小さな本棚の左上の列。
  • 武器のモジュール: 2階のターミナルコンソール付近、デスクの棚の中。
  • アーマーのモジュール: チェックインエリアの左奥にあるカウンターの、右下にある収納スペースの中。

登場作品

サニートップ・ベースロッジはFallout 76に登場します。

感想

戦前はサニートップ・スキー場のロッジでしたが、大戦後はかつての富裕層で構成される「ダイハーズ」レイダーたちの拠点の一つとなっていた場所です。

戦前のブラックな競技イベントによる「二人三脚レースでの怪我人発生事件」の噂など、リゾート地特有の戦前の黒いユーモアが感じられるメモも残っています。
